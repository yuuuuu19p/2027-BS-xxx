# 数据目录

| 子目录 | 用途 | 是否入库 |
|---|---|---|
| `metadata/` | 数据说明、字段 schema、统计信息 | ✅ 是 |
| `samples/` | 小样本 / 样例数据（便于复现） | ✅ 是 |
| `raw/` | 原始数据（体积大） | ❌ 否，见 .gitignore |
| `processed/` | 处理后数据（体积大） | ❌ 否，见 .gitignore |

## 约定

- 超过约 10 MB 的文件不入库；大文件存外部存储（网盘/服务器），在本文件登记路径与校验信息。
- 数据不可再分发时，只登记获取方式，不存样本。
