# 实验设计

> 初稿（2026-10-07），随实验推进更新。参数为建议值，以实际运行为准。

## 一、实验目的

在边缘资源受限（CPU/消费级 GPU）条件下，验证校园服务 RAG 问答系统的**回答质量**与**资源占用**表现，确定最优的"模型 / 量化 / 检索参数"组合，并量化 RAG 相对无检索 Baseline 的提升。

## 二、数据集

| 数据集 | 规模 | 用途 | 来源 |
|---|---|---|---|
| 校园服务知识库 | 待定（建议 500–2000 条文档/FAQ） | 建索引（RAG 实验用） | 校园官网 / 手册 / FAQ（确认版权与脱敏） |
| 标准问题集 | 50–100 题 | 评测集 | 按场景编写：教务 / 图书馆 / 后勤 / 网络 / 财务等 |

## 三、基线 / 对比方法

- **Baseline**：本地 LLM 直接问答（no-RAG），不注入检索上下文 → `experiments/baseline/`
- **对比方法**：RAG 完整链路及模型大小、量化方案、检索参数各变体（EXP-002 起）

## 四、评价指标

| 指标 | 定义 / 计算 | 主 / 次 |
|---|---|---|
| faithfulness | RAGAS：回答与给定上下文的忠实度 | 主（质量） |
| answer_relevancy | RAGAS：回答与问题的相关性 | 主（质量） |
| context_relevancy | RAGAS：检索上下文相关性（RAG 实验） | 主（质量） |
| 人工抽检 | 随机 N 题人工评分 | 次 |
| 显存占用 | nvidia-smi 峰值（MB） | 主（资源） |
| 内存占用 | 系统监视器峰值（MB） | 次 |
| 首 token 时延 / 总时延 | 计时（ms） | 主（性能） |
| 吞吐 | token/s | 主（性能） |

## 五、实验矩阵

| 实验编号 | 考察变量 | 固定项（建议） | 预期结论 | 对应目录 |
|---|---|---|---|---|
| EXP-001 | Baseline（no-RAG） | 1.5B 模型，INT4 | 质量最低，作为对照组 | `baseline/` |
| EXP-002 | RAG 完整链路 | 同模型量化 + Top-k=3、chunk=512 | 质量显著高于 EXP-001 | `exp01_rag_link/`（待建） |
| EXP-003 | 模型大小（1.5B vs 7B） | RAG + INT4 | 7B 质量更高、资源占用更高 | `exp02_model_scale/`（待建） |
| EXP-004 | 量化方案（INT8 vs INT4） | RAG + 1.5B | INT4 省资源，质量略有损失 | `exp03_quant/`（待建） |
| EXP-005 | RAG 前后质量对比 | 同模型同量化 | RAG 后回答更准确、更少幻觉 | 汇总 EXP-001/002 |
| EXP-006 | Top-k 扫参（1/3/5/10） | RAG + 固定 chunk | 存在最优 k | （并入 exp01） |
| EXP-007 | chunk size 扫参（256/512/1024） | RAG + 固定 Top-k | 存在最优切分 | （并入 exp01） |

> 拓展目标（可选）：缓存、更复杂检索策略、动态问题集，另设实验。

## 六、消融 / 参数敏感性

- 检索参数敏感性：EXP-006（Top-k）、EXP-007（chunk size）
- 消融对照：去掉检索（= EXP-001 Baseline）、固定量化对比模型大小（EXP-003）、固定模型对比量化（EXP-004）
