# 任务要求（最低完成要求 + 拓展目标）

> 来源：指导教师制定（2026-10-07 录入；若与任务书有出入，以任务书为准）

## 最低完成要求

1. 搭建 2–3 个 ESP32 节点；
2. 完成环境数据采集；
3. MQTT 上传；
4. Web 实时及历史监测；
5. 实现断网缓存；
6. 自动重连；
7. 数据补传；
8. 测试：
   - 数据完整率
   - 重连时间
   - 补传成功率
   - 端到端延迟
   - 节点数对性能影响

- 动态节点管理
- 更大规模并发测试
