# 任务要求（最低完成要求 + 拓展目标）

> 来源：指导教师制定（2026-10-07 录入；若与任务书有出入，以任务书为准）

## 最低完成要求

1. 建立校园服务知识库（资料采集、清洗、切分、向量化）与标准问题集；
2. 完成本地 LLM + RAG 完整链路：文档处理 → 向量检索 → 提示词组装 → 生成回答；
3. 提供 Web 问答界面，支持标准问题集问答与自由提问；
4. CPU/消费级 GPU 下的量化方案对比与资源测试（显存、内存、推理时延、吞吐）；
5. 至少比较两种模型大小或量化方案（INT8/INT4 等多量化方案、不同小模型）；
6. 测试 RAG 前后回答质量；
7. 研究 Top-k、chunk size 等至少一种检索参数对回答质量的影响；
8. 测试 / 评估项：
   - 回答质量（准确率 / 相关性 / 完整性，可用 RAGAS 等自动评测）
   - 资源占用（显存、内存）
   - 推理时延 / 吞吐
   - 模型大小 / 量化位宽对性能影响

## 拓展目标

- INT8 / INT4 多量化方案对比
- 不同小模型（多种模型大小）
- 回答缓存
- 更复杂检索策略
