## 一、研究问题

（初稿，题目确认后微调）

1. 研究对象：基于 ESP32 的多节点环境数据采集与远程监测系统。
2. 当前问题：常见环境监测方案部署成本高、节点离线时数据易丢失，缺乏统一的实时与历史监测平台。
3. 本论文拟解决：搭建 2–3 个 ESP32 采集节点，完成环境数据采集与 MQTT 上传，提供 Web 端实时及历史监测，并实现断网缓存、自动重连与数据补传机制，保证数据传输的可靠性与完整性。
4. 验证方式：通过数据完整率、重连时间、补传成功率、端到端延迟及节点规模对性能的影响等指标评估系统。
