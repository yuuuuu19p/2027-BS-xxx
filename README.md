## 一、研究问题

1. 研究对象：面向校园服务的 RAG（检索增强生成）智能问答软件 —— 建立校园服务知识库与标准问题集，构建 "本地大模型 + 检索增强生成" 的完整问答链路，并部署于 CPU / 消费级 GPU 等边缘受限环境。
2. 当前问题：校园服务信息分散、咨询需求量大，通用大模型缺乏校园专属知识且易产生 "幻觉"、回答失真；而本地部署大模型受算力、显存 / 内存资源限制，推理速度与资源占用难以平衡，检索参数（Top-k、chunk size 等）设置不当也会显著影响回答质量。
3. 本论文拟解决：在边缘资源受限条件下设计并实现一套可用的校园服务 RAG 问答系统，对比至少两种模型大小与 INT8/INT4 等多量化方案的资源开销与效果，测试 RAG 前后的回答质量差异，并研究 Top-k、chunk size 等至少一种检索参数对回答质量的影响。
4. 验证方式：以回答质量与资源占用（显存、内存、推理时延）等指标进行测试评估，得出资源受限场景下的最优 "模型 / 量化 / 检索参数" 组合，为校园服务智能问答的本地化部署提供可行方案。
