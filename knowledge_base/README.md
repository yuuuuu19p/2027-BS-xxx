# 知识库

> 存放不属于论文正文、但对研究有帮助的知识积累：学习笔记、技术调研、资料整理、课程/会议笔记等。

## 建议结构

按主题分子目录，例如：

```
knowledge_base/
├── mqtt/        # MQTT 协议、QoS、Broker 相关笔记
├── esp32/       # ESP32 开发、固件、外设笔记
├── web/         # Web 后端/前端、可视化笔记
└── README.md
```

## 约定

- 引用外部资料注明来源（URL / 出处）。
- 有版权限制的教材、论文 PDF 不入库，只登记标题与链接。
- 与论文直接相关的结论性内容最终以 docs/ 与 thesis/ 为准。
